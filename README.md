📚 KNOWLEDGE HUB LIBRARY

Read, Learn and Grow

1. Introduction

Knowledge Hub Library is a web-based library information system developed as part of the ICT 2102 – Web Development group practical assignment.

The website is designed to provide students, teachers and community members with information about library resources, services and activities. It promotes reading, research, digital literacy and lifelong learning.

2. Project Objectives

The objectives of this project are to:

- Promote a culture of reading and lifelong learning.
- Provide information about available library resources.
- Encourage research and academic development.
- Support access to digital learning resources.
- Make library information accessible to community members.

3. Website Features

The website includes the following sections:

1. Home Page: Introduces the library and welcomes visitors.
2. About Us: Explains the library's mission and purpose.
3. Books and Resources: Presents different learning and reading categories.
4. Library Gallery: Displays images related to reading and learning.
5. Membership Registration: Provides a membership registration form.
6. Book Request: Allows visitors to request books.
7. Feedback: Allows visitors to submit comments and suggestions.
8. Library Rules: Explains the expected conduct of library users.
9. Library Schedule: Presents sample library activities and schedules.

4. Technologies Used

- HTML5 – for website structure and content.
- CSS3 – for styling, colours, layouts and responsiveness.
- JavaScript – where applicable, for interactive features.

6. Target Users

The website is intended for:

- Students
- Teachers and educators

7. Educational Importance

The project demonstrates how web development technologies can be used to create an organised and accessible platform for sharing educational information. It also provides practical experience in designing web pages, creating forms, applying CSS and organising website files.
